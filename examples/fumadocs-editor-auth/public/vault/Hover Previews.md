# Hover Previews

Hover or focus a link to a Note and a preview opens. This one is previewed by every link to it.

## Nested previews

Links inside a preview open their own. Start here: [[Preview Chain One]]. Inside it, keep going.

## Subpaths

A link to a heading previews just that section: [[Callouts#Foldable]]. A link to a Block ID previews that block: [[Comments and Block IDs#^linkable]].

## No preview

Unresolved links ([[Nowhere]]), images ([[sample.svg]]) and external links ([Example](https://example.com)) open none.
