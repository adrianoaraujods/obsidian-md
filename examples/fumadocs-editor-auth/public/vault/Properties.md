# Properties

The panel above this heading lists this Note's Frontmatter: text, a list of tags, a date, a date with a time, a checkbox, a number and links. The link to `Missing Note` is unresolved.

The panel starts expanded here and collapsed in a [[Hover Previews|Hover Preview]]. It remembers your choice for each.
