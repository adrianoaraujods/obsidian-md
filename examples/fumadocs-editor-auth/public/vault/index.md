# Sample Vault

This Vault is the demo for `remark-obsidian-md`. Every Note shows one feature, with the Obsidian source next to what it renders. Hover any link to a Note to open a [[Hover Previews|Hover Preview]].

## Tour

- [[Wiki Links]]: Aliases, Subpaths and unresolved links
- [[Embeds]]: Notes, sections, blocks and images
- [[Callouts]]: every built-in type, foldable too
- [[Highlights]]: with Highlight Colors
- [[Comments and Block IDs]]: hidden text and linkable blocks
- [[Properties]]: Frontmatter in the Properties Panel
- [[Hover Previews]]: nested previews, to any depth
